# Two Street Water Ice

A responsive landing page for a fictional Philadelphia water ice stand, featuring flavor displays, size options, and location information.

##  About

Two Street Water Ice is a beloved corner stand in Pennsport, Philadelphia, serving authentic water ice since 1988. This website showcases their daily flavors, cup sizes, and helps customers find the stand at the corner of 2nd & Dickinson.

The site captures the nostalgic, neighborhood feel of a classic Philly water ice stand with bold typography and a warm, inviting design.

##  Features

- **Responsive Design**: Mobile-first layout optimized for all devices
- **Flavor Board**: Dynamic display of daily flavors with descriptions
- **Size Options**: Clear pricing and descriptions for all cup sizes
- **Location Info**: Hours, address, and house rules for visitors
- **Smooth Navigation**: Anchor links to page sections
- **Accessible**: Semantic HTML and proper heading hierarchy
- **No Dependencies**: Pure HTML and CSS

## Technologies

- HTML5
- CSS3 (Flexbox, Grid)
- Google Fonts (Gabarito, Roboto, Source Sans 3, Titan One)
